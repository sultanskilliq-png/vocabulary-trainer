# Vocabulary Trainer

A simple Python program that helps you remember English words.
You add words with their meaning and an example, then the program tests you.

## How to run

1. Install Python 3.
2. Run: `python trainer.py`

## Features

- add: save a new word, its meaning, and an example
- quiz: answer 3 questions; hard words appear more often
- repeted: show one random hard word
- total: show how many words you have
- wrong: show your hardest words
- q: quit

## Notes

- Words are saved in `vocabulary-trainer.json`.
- I used AI to help with my English spelling.
